# 结论体检器 · verdict_checkup

> **by Qiyuan & Xiaoxuan**　·　纯标准库 · 零依赖 · MIT License

> 一个帮你给「用数据支撑的结论」做体检的工具。
> 它不告诉你结论对不对，它告诉你：**这个结论能不能站住、病在哪、用了什么判据、哪些地方它根本判不了。**

你手里有一个「看起来很有数据支撑」的结论，比如：
- 「全球贫困率从 43% 降到 10%，减贫成效显著」
- 「晶体管数持续指数增长，摩尔定律稳定成立」
- 「这 6 个网络都符合小世界特性」
- 「某指标过去 30 年稳步上升」

这些结论**可能对，也可能踩了同一类坑**：构成漂移、指数被当直线、单点噪声冒充趋势、数据边界外瞎外推……
`verdict_checkup` 就是把这些年真实踩过的坑，固化成 8 项可执行的自动检查。

---

## 它不做的事（先说清楚，免得你误解）

- ❌ 它**不**判断你的结论是否科学真理。
- ❌ 它**不**给你「通过=正确」的背书。**pass 只表示「未发现结构性硬伤」，不是「结论成立」。**
- ❌ 它在数据不足时**会说「判不了」（cannot_judge）**，而不是硬塞成 pass 或 fail。这是它的核心设计——**二元对立会吞掉「证据不足」这个合法类别。**

---

## 8 项检查

| # | 检查 | 抓什么坑 |
|---|------|---------|
| 1 | 数字量级 | 数值跨太多个量级 → 疑似单位混用/量纲错 |
| 2 | 趋势 vs 噪声 | 单调性判据 + R²；**指数增长自动识别**（防把指数当直线判「趋势弱」） |
| 3 | 数据边界 | 结论涉及的时间/范围超出数据覆盖 → 边界外部分是「编的」 |
| 4 | 样本量 | N 太小撑不起强结论 |
| 5 | 证据等级 | 「读到的」vs「算到的」vs「转述的」；二手转述风险 |
| 6 | 观测量配不配 | 分布断尾/单点占比过高 → 这不是「积累-崩溃」型雪崩，别拿它拟合幂律 |
| 7 | 同类判定（数值≠身份） | 两系统指数数值接近，但分段漂移差大 → 数值巧合 ≠ 同机制 |
| 8 | 样本构成漂移（辛普森陷阱） | 分组权重/样本总数跨层漂移 → 跨层汇总会辛普森反转，必须分层看 |

每项给出 `verdict ∈ {pass, warn, fail, cannot_judge}`，并说明**判据**与**坑在哪**。

## 快速开始

> **前提**：只要 `python3`（3.7+，纯标准库，零第三方依赖）。先 `cd` 进本目录，下面的命令都在这里跑。

```bash
# ① 手上只有一列数字？（每行一个值，最省事）
python3 checkup_cli.py --claim "这个指标持续下降" --values examples/declining_series.txt --verbose

# ② 有带表头的时间序列 CSV（两列: x 和 y）
python3 checkup_cli.py \
  --claim "晶体管数持续指数增长，摩尔定律稳定成立" \
  --csv examples/moore_transistors.csv --x year --y transistors --verbose

# ③ 带「分组权重」文件（每行: 分层标签 权重0~1），抓辛普森陷阱
python3 checkup_cli.py --claim "录取率差异是真实的" --group-weights examples/gw.txt --verbose

# ④ 自检（负向+正向用例全跑一遍，证明工具自己没坏）
python3 checkup_cli.py --selftest
```

> `examples/` 里放了几个**能直接跑通**的真实数据切片（伯克利 1973 辛普森悖论、全球贫困、摩尔定律），先拿它们试手最省事。
>
> 用错模式它会说人话提醒你 —— 比如你拿一份「一列数字、没表头」的文件去用 `--csv`，
> 它会告诉你「看起来只有一列数字，用 `--values` 直接喂」。

**零第三方依赖，只要 `python3`**（纯标准库）。

## 🏆 王牌案例：两次真实数据盲测踢馆

> 下面两份战报，是拿**公开真实数据**、**不预设结论**、现场跑出来的。原始数据切片就在 `examples/` 里，可自行复跑。

### 案例 1 · 全球贫困「持续改善」——构成漂移与口径

- **数据**：OWID / World Bank，全球 `$3/天` 贫困率，1990 年 43.4% → 2026 年 9.8%（37 年）
- **体检**：✅ 趋势 vs 噪声 **R²=0.966 强趋势**（真趋势，不是噪声）
- **防呆预警**：
  1. **口径**：用的是 `$3/天`。换 `$2.15` 或 `$6.85`，降幅大不同——「成效显著」依赖你选哪条线。
  2. **构成漂移**：覆盖国家数 1990=36 国 → 2010=97 国（2.7 倍）。工具判 **warn**（未到 3 倍 fail 阈值）。
     - **这是工具的克制**：它没有因为「覆盖变多」就武断判「减贫是假的」——因为贫困率按人口加权，1990 年 36 国已覆盖大部分发展中国家人口。**漂移 ≠ 造假。**
  3. **诚实边界**：数据真、趋势真、减贫真。体检的价值不是「戳穿减贫」，是提醒「这个结论依赖特定口径，需限定条件」。

### 案例 2 · 摩尔定律「稳定外推」——现场抓出并修好一个真 bug

- **数据**：OWID 晶体管数，1971（2308）→ 2021（582 亿）

**第一幕 · 暴露 bug**：初测报 `R²=0.333（中等），趋势需谨慎`。一条翻了 2500 万倍的极干净指数曲线被判「趋势弱」。
→ 取对数再喂 → **R²=0.994**。差 0.66，确认这是**「指数被当直线拟合」的尺子问题**，不是数据趋势弱。
→ 修复：给趋势判据加「指数增长识别」（y 全正且对数拟合远好于线性 → 用对数 R² 并标注），5 条负向+正向测试全绿（含「线性趋势不被误标成指数」的假阳性防护）。

**第二幕 · 修好后仍诚实标注盲区**：
- 修后 ✅ `【指数增长·对数尺度拟合】R²=0.994`，总评通过。
- **但「未来仍每 2 年翻倍」站不住**：分段实测翻倍时间 2000-2010 是 **1.68 年** → 2010-2018 **2.51 年**（放缓 50%）→ 2018-2021 回升 2.05 年。
- **全段高 R²=0.994 掩盖了近年速率波动。外推是趋势判据的结构性盲区——工具判 pass 只代表「历史符合指数」，不代表「未来可外推」。**

---

## 两次踢馆的共同主命题

> 一个结论体检器的价值，不在「它能给你 pass」，而在：
> 1. **能抓住它设计覆盖的坑**（构成漂移 / 趋势噪声 / 指数识别）；
> 2. **数据不足时诚实报「判不了」**，不冒充通过；
> 3. **在能力边界外（如外推）不假装**，把边界写清楚。
>
> **pass 从来不是「结论正确」的证明，只是「未发现结构性硬伤」的陈述。**

## 设计哲学：先把「尺子坏」拆开

这套工具来自一个反复撞到的教训：**「尺子坏」有几种形态，防的姿势各不相同**——

| 坏法 | 表现 | 对应检查 |
|------|------|---------|
| 量纲错 | 单位乘错，数字量级荒谬 | #1 数字量级 |
| 取样错 | 没踩到拐点，数字合理但结论反了 | #2 #7 |
| 世界错 | 判据忠实测量了我人为构造的偏世界 | 需人补（工具测不出你的世界是不是虚构的） |
| 观测量错 | 拿完好的尺子量了不属于它量程的东西 | #6 |
| 时间窗错 | 观察窗口太短，伪造的不是数字是趋势 | #2 |
| 外推错 | 历史拟合好 ≠ 未来成立 | **工具盲区，需人补** |

**工具能自动抓前四种；后两种（世界是不是你虚构的、未来能不能外推）它抓不到，必须你自己盯。**

## 一个诚实的自我声明

这工具是从真实踩坑里长出来的，不是设计大会上空想出来的。它的每一项检查，都对应一次「我拿着漂亮数字差点骗了自己」的经历。所以它对「漂亮但有坑的结论」比较敏感——**但它也有盲区（世界错、外推错），那些地方你得自己补。**

如果你用它踢出一个它漏掉的坑，那是它该长大的地方。
